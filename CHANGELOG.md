# Changelog

## 0.2.0 — 2026-10-14

- Adapt to official DeepSeek Harness 0.2.1-alpha.2 and its released npm dependencies.
- Use volatile profile Config, ConfigForms and current renderer hook injection.
- Add automatic bundle activation, literal-brace handling, save failure feedback and retry.
- Validate official artifacts, profile persistence, actual Web installation and browser interactions.
- Provide a non-overwriting legacy migration proposal and retain the 0.1.0 release.

## 0.1.0 — 2026-10-13

- Extract the original global prompt implementation into an independently named community plugin.
- Preserve the global settings namespace, prompt section, bilingual Web UI and four existing test suites.
- Add pinned-harness setup/build/test scripts, typed outputs, a profile replacement overlay and CI configuration.
- Add built Loader/file persistence/restart and browser factory smoke verification.
- Declare the exact supported development commit and the unverified status of current upstream.
